# Quality gates

## Narrative gate

- The audience and requested action are explicit.
- The opening creates a reason to continue.
- Each slide advances one claim and creates the need for the next.
- The closing resolves the opening and asks for an appropriate action.
- No repeated agenda, generic summary, or empty “Thank you” ending.

## Evidence gate

- Facts, judgments, and unknowns remain distinguishable.
- All meaningful numbers have source, date, and definition.
- Missing information appears as a specific `[待补充：...]` marker.
- No invented quote, person, customer, data point, test result, or source.
- Externally researched claims and assets are traceable in notes.

## Copy gate

- Visible copy is written for the audience.
- Titles state takeaways rather than production instructions.
- One slide does not attempt to make multiple unrelated arguments.
- Text is shortened before font size is reduced.
- Long identifiers and URLs are kept out of primary slide copy.

## Visual gate

- The deck uses one coherent visual system.
- Adjacent slides vary silhouette when the content calls for it.
- Visuals carry information rather than merely decorating empty space.
- No competitor trademark, proprietary copy, restricted asset, or unlicensed template is copied.
- Native objects remain editable where practical.

## File gate

- Every slide renders successfully.
- Every slide is inspected at full size.
- No unintended overlap, clipping, text overflow, broken connector, or unresolved placeholder.
- Speaker notes and sources are present where required.
- The PPTX opens in at least one compatible presentation application and retains editable text.

## Release severity

- **P0**: invented key fact, file cannot open, wrong customer/project data, confidential leakage. Block delivery.
- **P1**: wrong audience/scenario, missing decision, important overflow, missing required source. Block delivery.
- **P2**: generic wording, weak visual variation, minor spacing inconsistency. Fix when it materially affects use.
